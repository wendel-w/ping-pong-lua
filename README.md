# ping-pong-lua

This is a ping-pong game (with some extras) written in lua with the love2d framework

### Installation

1. Make sure you have love2d installed. If you havent installed it, check love2d's official website on how to do it: https://love2d.org/ .

2. Clone the repository:
   ```bash
   git clone git@github.com:wendel-w/ping-pong-lua.git
3. Run it
    ```bash
    cd ping-pong-lua
    love .

### Configuration

Feel free to take a peek into `config.lua` and edit it if you want to. There you can modify the proporitons of the drawn elements, the controls, or the balancing.
